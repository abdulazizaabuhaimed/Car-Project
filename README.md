# Saudi Used Car Price Prediction 🚗

## Overview

This project focuses on predicting used car prices in Saudi Arabia using Machine Learning techniques and real-world market data.

The goal of the project is to analyze the factors affecting used car prices and build a predictive model capable of estimating fair market prices for vehicles.

## Dataset

- **8,035 original records**
- **5,462 cleaned records**

## Technologies Used

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Scikit-learn**
- **Jupyter Notebook**

## Model Performance

- **R² Score → 0.718**
- **RMSE → 34,953**
- **MAE → 21,422**
